DIONY AI — START HERE
=====================

Diony runs locally in your web browser and shoots through cloud APIs. It does
not install a Mac or Windows application and it does not run a local video or
language model.

YOU NEED
--------

1. Python 3.11 or newer.
2. ffmpeg and ffprobe on PATH.
3. At least one camera house:
   - Grok Imagine: XAI_API_KEY
   - Google Flow: USEAPI_TOKEN, a linked Google account, and captcha capacity;
     plus GEMINI_API_KEY for the Google screenwriter and narrator

KEYS
----

Create ~/.diony/keys.env and add only the lines you use:

    XAI_API_KEY=xai-...
    USEAPI_TOKEN=user:...
    DIONY_FLOW_EMAIL=you@example.com
    DIONY_FLOW_PLAN=pro
    GEMINI_API_KEY=AIza...

Keep that file private. Diony reads it but never writes keys.

Google Flow starts with 300 captcha solves included by useapi.net. After they
are used, configure a solver such as CapSolver on the useapi.net account:

    https://useapi.net/docs/api-google-flow-v1/post-google-flow-accounts-captcha-providers

The CapSolver API key is sent to useapi.net on that page. Do not put it in
~/.diony/keys.env; Diony only needs USEAPI_TOKEN after the account is linked.

RUN
---

Mac or Linux:

    ./open-diony.sh

Mac Finder:

    Open Diony AI.command

Windows Explorer:

    Open Diony AI.bat

The launcher creates .venv when necessary, starts Studio, Director, and
Producer, then opens Studio in your browser. Leave its terminal open and press
Ctrl-C when you want to stop Diony.

LOCAL URLS
----------

    Studio     http://127.0.0.1:8787
    Director   http://127.0.0.1:8790
    Producer   http://127.0.0.1:8788

No administrator password, hosts-file edit, .diony.local name, installer, or
desktop bundle is needed.

BEFORE SPENDING
---------------

After the first launch:

    .venv/bin/diony-director-check
    .venv/bin/diony-director-check --live

The first command is offline. The second checks provider authentication
without rolling a clip. Diony still requires camera selection, script lock,
cast approval when applicable, a visible estimate, and the two-step Run
confirmation before generation.

At the Cast/BIBLES gate, use "Use your image as anchor" beside a character to
provide that character's face as a PNG, JPEG, or WebP (up to 10 MB). Diony
keeps it in the local vault and draws the rest of that character's sheet from
your image before asking you to approve the face.

If the character already exists in Google Flow, choose "Use existing Flow
character" on the same BIBLES card and select it from Diony's Flow library;
you can also paste its Flow character page URL or API reference. Diony verifies
it against DIONY_FLOW_EMAIL and references that reusable character in compatible
Flow clips instead of creating a duplicate.

Everything generated is downloaded into .diony-vault by default. The receipt,
subtitles, edit data, assembly map, and QC packet stay with the finished film.
