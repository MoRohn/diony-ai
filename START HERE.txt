Diony AI — first open

Diony makes a film from one line. It writes the script, prices every
shot, shoots on cloud video models, reviews each clip, cuts the film,
narrates it, and hands you the master with its receipt.

You need no GPU. You need two things: a provider account and ffmpeg.


------------------------------------------------------------------------
1. Get a provider account (one is enough, two is better)
------------------------------------------------------------------------

  A. Grok Imagine (xAI)
       https://console.x.ai/
       Create an API key. Billing is metered: about $0.14 per second
       of 720p video on grok-imagine-video-1.5, a few cents per still.
       The same key powers the narrator voice and the screenwriter.

  B. Google Flow (through useapi.net)
       1. A Google account on a Google AI plan
          https://one.google.com/ai  (Plus, Pro, or Ultra)
          Flow is charged in that plan's monthly credits:
          Plus 200 · Pro 1,000 · Ultra $99.99 10,000 · Ultra $199.99 25,000
       2. A useapi.net subscription and token
          https://useapi.net/  →  Google Flow  →  link your Google account
       3. Note the email of the linked Google account.

  Pick A if you want exact per-second pricing and 15-second takes.
  Pick B if you want native voices, locked characters, and a free 1080p
  finish. With both, the Director chooses per shot.


------------------------------------------------------------------------
2. Install ffmpeg
------------------------------------------------------------------------

  Mac        brew install ffmpeg
  Windows    https://ffmpeg.org/download.html  (put ffmpeg.exe and
             ffprobe.exe on your PATH)
  Linux      sudo apt install ffmpeg

  Diony cuts, mixes, and reviews every film with it.


------------------------------------------------------------------------
3. Put the keys in one private file
------------------------------------------------------------------------

Create the folder ~/.diony and inside it a file named keys.env.
Windows: C:\Users\YOUR_USER\.diony\keys.env

  XAI_API_KEY=xai-...
  USEAPI_TOKEN=user:...
  DIONY_FLOW_EMAIL=you@gmail.com
  DIONY_FLOW_PLAN=pro

Only the lines for the accounts you have. DIONY_FLOW_PLAN is one of
plus, pro, ultra-99, ultra-199 and prices Flow credits in dollars.

Mac / Linux: chmod 600 ~/.diony/keys.env

Diony reads this file and never writes it. There is no key form in
the app. Keys never leave this computer except to the provider they
belong to.


------------------------------------------------------------------------
4. Open the software (this folder)
------------------------------------------------------------------------

When the Diony webpage is live, choose Download for Mac or Download
for Windows, install Diony AI normally, and open the app. The installed
app includes its own runtime: no Python, pip, Terminal, or source
folder is required. The steps below are the source-folder path for
engineers and pre-release systems; they need Python 3.11 or newer
from https://www.python.org/downloads/

  1. Double-click the Open Diony AI file:
       Mac          Open Diony AI.command
       Windows      Open Diony AI.bat
       Linux        open-diony.sh

     Mac developers can double-click Build Diony AI.command instead:
     it builds the native Diony.app from this folder and opens it.

  2. If a Mac warning says the file cannot be opened: right-click
     it, choose Open, then Open.

  3. A browser page opens. Wait until Continue. Click Continue.
     That is Studio (http://studio.diony.local). The first open may
     ask for this computer’s password once — that lays the names
     studio, director, and producer .diony.local. Approve it. If you
     cancelled, Continue on the lobby retries.

  4. Leave the small Terminal window open until it says you can
     close it. Closing it during the first setup stops the install.


------------------------------------------------------------------------
5. Make a film
------------------------------------------------------------------------

  1. Studio shows two cards: Grok Imagine and Google Flow. A green
     chip means the key was found. Pick the camera and press
     Continue to the Director. One camera shoots the whole film.

  2. In the Director, describe the film. One line is enough. Set the
     Duration. Drop reference stills if you have them.

  3. Press Draft script. The script appears in a minute or two.
     Edit any line. Press Lock script & price the clips. The reply
     names the exact price. Nothing has rolled.

  4. Approve the faces in the cast dock.

  5. Press Run & Assemble All. Watch the run strip. When it says
     That’s a wrap, the film is in the Producer Gallery with its
     receipt, subtitles, edit list, and QC packet.

Your films live in the vault:
  Mac / Linux    /diony/vault if it exists, else apps/producer/data in this folder
  Set DIONY_VAULT to choose.


------------------------------------------------------------------------
6. Check the keys before spending
------------------------------------------------------------------------

From a Terminal in this folder, after the first open:

  .venv/bin/diony-director-check            what was found, no network
  .venv/bin/diony-director-check --live     free auth probes, both providers
  .venv/bin/diony-director-check --roll-one grok --yes
                                            one 1-second clip, about $0.08

Optional, both free:
  --stage-face-models   downloads the face models Cast Lock measures with
  --reconnect           re-links a signed-out Google Flow account


------------------------------------------------------------------------
7. If something is wrong
------------------------------------------------------------------------

  NO KEY / NO TOKEN on a Studio card   the keys.env line is missing or
                                        the file is in the wrong place
  Run paused                            the provider’s quota window; it
                                        resumes itself, nothing was spent
  A clip was refused                    press Retake — the opening frame
                                        is redrawn; Skip shot leaves it out
  “install ffmpeg”                      step 2
  The page will not open                the lobby’s Continue retries the
                                        name setup; the services also
                                        answer on http://127.0.0.1:8787,
                                        :8790, and :8788
