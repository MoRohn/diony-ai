Diony STUDIO

Choose your camera.

Studio configures the shoot; the Director runs it; Producer monitors the production and holds the Gallery. Every shot of a film rolls on the camera you pick here — you can change it any time.

Keys load from ~/.diony/keys.env

A key is required

Every shot rolls on a cloud camera you pay for directly, so the Studio needs at least one key before the Director can shoot. Diony never asks for a key in the app: put the lines you have in ~/.diony/keys.env and reopen this page.

Grok Imagine — an xAI API key from console.x.ai. Metered per second of video; the same key powers the narrator voice and the screenwriter.

Google Flow — a useapi.net token. useapi.net is a relay that gives API access to Google Flow: you link a Google account that has a Google AI plan (Plus, Pro, or Ultra), and Flow charges that plan's monthly credits per generation while useapi.net bills a flat subscription. See the Google Flow API docs.

XAI_API_KEY=xai-...
USEAPI_TOKEN=user:...
DIONY_FLOW_EMAIL=you@gmail.com   # the linked Google account
DIONY_FLOW_PLAN=pro              # plus | pro | ultra-99 | ultra-199
